## How to Run Locally
```bash
git clone https://github.com/Mdmustafasalman748/mustafasalmanmohammed.github.io.git
cd mustafasalmanmohammed.github.io
# no build step — just open index.html in a browser,
# or serve it locally:
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
